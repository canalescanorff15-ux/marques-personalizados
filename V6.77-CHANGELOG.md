# V6.77 — Checkout enxuto no orçamento

## Experiência mobile
- Adicionada barra fixa de checkout na página de orçamento.
- Exibe quantidade de peças, progresso do briefing e valor inicial conhecido.
- CTA `Finalizar` permanece acessível durante a revisão.
- Respeita o dock mobile da Merlin e `safe-area-inset-bottom`.
- A barra some quando o drawer de orçamento está aberto, evitando sobreposição de ações.

## Fluxo de orçamento
- Na página `/orcamento`, o drawer deixa de repetir visualmente o bloco completo de briefing.
- A lista de itens do drawer fica mais curta porque os produtos já foram revisados no planejador.
- O link `Abrir orçamento completo` não aparece quando o cliente já está no orçamento completo.
- A etapa final concentra contato, data, observações e envio.

## Infraestrutura
Sem alteração de banco, schema, migrations, API de inquiries, CRM, autenticação, MFA, storage, R2, backup ou restauração.
