# V6.79 — Image delivery e header mais leve

## Home
- Hero passa a usar `next/image` com prioridade e `sizes` responsivos.
- Categorias e produtos em destaque usam imagens otimizadas pelo Next.
- Menos instâncias client-side de `SafeImage` na página inicial.
- Consulta da seleção de produtos reduzida ao necessário para a Home.

## Imagens
- AVIF e WebP habilitados no otimizador.
- Qualidades utilizadas pela Home declaradas explicitamente para Next 16.
- Cache mínimo das variantes otimizadas configurado para uma hora.

## Header
- Scroll do cabeçalho passa a usar `requestAnimationFrame`.
- React só recebe atualização quando o modo compacto realmente muda.
- Logo pequena recebe dimensões explícitas e fallback sem componente de estado adicional.

## Infraestrutura
Nenhuma alteração em banco, schema, migrations, CRM, inquiries, autenticação, MFA, Cloudflare R2, backups ou restauração.
