# V6.84.1 — Netlify preview build fix

## Diagnóstico

O deploy preview da V6.84 falhava antes da publicação apesar de TypeScript, `next build` e E2E passarem no GitHub Actions.

A causa identificada foi de configuração de ambiente do Netlify: `netlify.toml` executa `npm run check:env -- --production` também em Deploy Previews, e a variável pública `NEXT_PUBLIC_WHATSAPP_NUMBER` estava configurada apenas no contexto `production`. As demais variáveis obrigatórias já estavam disponíveis no contexto `deploy-preview`.

## Correção aplicada

- `NEXT_PUBLIC_WHATSAPP_NUMBER` passou a existir também em `deploy-preview`;
- a mesma variável pública foi habilitada em `branch-deploy` para manter os builds de validação consistentes;
- nenhuma credencial privada foi relaxada ou exposta;
- nenhuma regra de banco, autenticação, MFA, R2, backup ou CRM foi alterada.

## Segurança

A variável ajustada é um dado público de contato comercial, já renderizado no próprio site. Os segredos administrativos continuam com escopos protegidos no Netlify.

## Validação

Este commit existe para disparar um novo Deploy Preview e confirmar o build da V6.84 no ambiente real do Netlify antes de promover qualquer nova publicação em produção.
