# V6.81 — Image Performance & CSS Scope

## Objetivo
Reduzir bytes desnecessários no carregamento público sem alterar o fluxo comercial, banco de dados ou infraestrutura crítica.

## Alterações
- `SafeImage` passou a usar `next/image` com AVIF/WebP, `srcset`, `sizes` responsivos e fallback resiliente.
- SVG, `data:` e `blob:` continuam seguros via modo não otimizado.
- Logo do header passou a usar a mesma camada resiliente de imagens.
- Galeria de produto recebeu tamanhos responsivos específicos para imagem principal, miniaturas e lightbox.
- Busca global passou a solicitar miniaturas compatíveis com os 54 px realmente exibidos.
- Vistos recentemente passou a solicitar imagens proporcionais ao grid responsivo.
- CSS exclusivo da Home (`home-v672.css` e `home-v673.css`) deixou de ser carregado globalmente.
- Novo `shell-v681.css` mantém somente header, navegação e proteções globais necessárias em todas as rotas.
- A Home continua carregando integralmente sua identidade visual, agora de forma local à própria rota.

## Preservado
Sem mudanças em Neon, schema, migrations, APIs, CRM, orçamento, autenticação, MFA, sessões, Cloudflare R2, backups ou restauração.

## Validação esperada
- TypeScript sem erros.
- Build de produção aprovado.
- Contratos de segurança e infraestrutura intactos.
- E2E HTTP e smoke de concorrência aprovados.
- Verificação do deploy Netlify após merge.
