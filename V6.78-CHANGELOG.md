# V6.78 — Performance hardening

## Runtime visual
- Scroll progress passa a usar `requestAnimationFrame` para evitar múltiplas escritas por frame.
- Pointer aura também usa atualização coalescida por frame.
- `MutationObserver` fica responsável apenas por registrar novos elementos com reveal.
- `ResizeObserver` acompanha mudanças reais de altura da página e agenda o recálculo de progresso.

## Analytics e Web Vitals
- Page view é adiado para idle time, com fallback por timeout.
- Cliques em WhatsApp e redes sociais continuam rastreados imediatamente.
- TTFB deixa de gerar request durante a renderização inicial e passa a ser enviado junto com LCP/CLS após a janela de coleta.

## CSS
- `quote-v677.css` deixa o layout global.
- Novo `app/orcamento/layout.tsx` carrega esse CSS somente na rota de orçamento.

## Infraestrutura
Nenhuma alteração em Neon, banco, schema, migrations, CRM, inquiries, autenticação, MFA, R2, backups ou restauração.
