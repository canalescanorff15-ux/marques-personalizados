# V6.90 — catálogo com referências fotográficas reais

- Substitui o sistema visual conceitual em SVG por uma biblioteca de fotografias reais de papelaria e festa.
- Incorpora seis referências fornecidas/aprovadas: topo floral dourado, mesa de primeiro aniversário, caixas florais personalizadas, cupcakes woodland, topo bailarina rosa e lembranças botânicas verde/dourado.
- As mesmas fotos passam a alimentar catálogo, ficha individual, comparador, curadoria guiada e o passo de inspirações do “Monte seu Kit”.
- O mapeamento é semântico: caixas usam referência de caixas, woodland/safari usa cupcakes temáticos, bailarina/princesa usa o topo rosa, lembranças e ocasiões elegantes usam a linha botânica, e topos/florais usam a referência de bolo.
- Mantém fallback determinístico para as 128 inspirações para que nenhum card volte a ficar sem imagem.
- Assets foram convertidos para WebP e servidos localmente pelo próprio site, sem dependência de hotlink externo.
- Atualiza o contrato de inspiração para exigir fotografia real e impedir regressão para monogramas, placeholders ou SVG conceitual.
- Não altera Neon/schema, CRM, orçamento, autenticação, MFA, sessões, preços, service worker ou API de pedidos.
