# GitHub Summary — V8.05

## Objetivo

Transformar "Produtos Criativos" em uma área comercial real do site, deixando de depender apenas de cards que levam direto ao orçamento.

## Entregue

- nova rota pública `/personalizados`;
- página "Papelaria & Personalizados" com identidade V8;
- linhas separadas para:
  - Caixinhas;
  - Lembrancinhas;
  - Adesivos & Chaveiros;
  - Doces & Complementos;
  - Kits Personalizados;
  - Outros Personalizados;
- cada linha possui descrição, exemplos do que pode ser produzido e CTA específico;
- Home agora direciona para a página de personalizados em vez de mandar direto para orçamento;
- header e rodapé apontam para `/personalizados`;
- bloco explícito "o que pode estar incluso / o que não está incluso";
- reforço de que bolo, doces, balões, painel, flores e decoração do ambiente não fazem parte do produto por padrão;
- fluxo de pedido em três etapas;
- layout responsivo para desktop, tablet e celular.

## Política visual preservada

- nenhuma máscara preta sobre imagens;
- produto é o foco;
- cenários completos não devem ser tratados como item vendido;
- referências servem para tema, composição e acabamento.

## Escopo preservado

Sem alterações em banco, schema, autenticação, Admin, orçamento, R2, favoritos ou regras de produção.
