# V6.71 — Migração Netlify + Neon + Cloudflare R2

## Objetivo

Preparar a Merlin Encantos em Papel para sair do Runsite sem converter a aplicação para site estático e sem remover backend, Admin, CRM, APIs, Neon, MFA, backups ou lifecycle de mídia.

## Mudanças

- Adicionado `netlify.toml` para Next.js híbrido via OpenNext.
- Build do Netlify executa contrato de plataforma, preflight de produção e `next build`.
- Node fixado em 22.23.2 também no Netlify.
- Skew protection habilitada para reduzir erros durante troca de deploy.
- Adicionado `NETLIFY.md` com migração, variáveis, teste e rollback.
- Adicionado `.env.netlify.example` sem segredos reais.
- Cloudflare R2 adotado como storage recomendado por encaixar na camada S3-compatible existente.
- Bucket de mídia, bucket de backup e bucket de drill documentados como destinos distintos.
- `.env.example` atualizado com configuração R2 e prefixo `merlin-backups`.
- Runsite passa a ser documentado como caminho legado/rollback.
- Adicionado `check:netlify` e contrato automático `scripts/netlify-r2-contract-check.mjs`.
- GitHub Actions executa o contrato Netlify/R2 antes do build.
- Nenhuma migração de banco.
- Nenhuma reescrita do upload para filesystem efêmero ou Cloudinary.

## Arquitetura

GitHub → Netlify/OpenNext → Next.js APIs/SSR → Neon PostgreSQL

Admin upload → Route Handler Node.js → Cloudflare R2 S3-compatible

Backups → GitHub Actions → bucket R2 privado separado
