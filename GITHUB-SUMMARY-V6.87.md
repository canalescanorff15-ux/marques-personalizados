# GitHub Summary — V6.87

## Objetivo
Substituir artes genéricas/geométricas do catálogo e das inspirações por imagens fotorealistas de referência, preservando transparência sobre o caráter ilustrativo e mantendo fotos reais enviadas pelo Admin como prioridade.

## Direção
- Imagens novas otimizadas em WebP.
- Catálogo passa a preferir fotos reais do Admin; quando o banco ainda aponta para SVGs antigos de `/catalog/`, usa as novas referências realistas locais.
- Inspirações deixam de usar monogramas/ornamentos abstratos e passam a exibir fotografia de referência.
- Imagens de referência continuam claramente identificadas como ilustrativas, sem serem apresentadas como trabalhos reais já produzidos pelo ateliê.

## Gate
PR + CI completa + Deploy Preview antes do merge.
